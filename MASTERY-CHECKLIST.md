# Mastery Checklist

Check an item only when it can be demonstrated without AI generating the answer.

## Programming

- [ ] Break a requirement into inputs, outputs, rules, and failure cases.
- [ ] Choose an appropriate array, object, map, set, or class.
- [ ] Explain primitive values versus object references.
- [ ] Use pure functions where side effects are unnecessary.
- [ ] Handle expected errors explicitly.
- [ ] Read unfamiliar TypeScript and trace its control flow.
- [ ] Write and debug automated tests.

## JavaScript and Node.js

- [ ] Explain scope, closures, prototypes, and modules.
- [ ] Explain the call stack, task queues, promises, and the event loop.
- [ ] Distinguish CPU-bound work from I/O-bound work.
- [ ] Handle process signals and graceful shutdown.
- [ ] Use files, buffers, and streams safely.

## HTTP and web

- [ ] Trace browser → DNS → TCP/TLS → proxy → server → database → response.
- [ ] Choose correct methods, status codes, headers, and content types.
- [ ] Explain cookies, sessions, tokens, CORS, and caching.
- [ ] Build and test an HTTP server without a framework.

## Databases

- [ ] Design normalized tables with useful constraints.
- [ ] Write joins and transactions without an ORM.
- [ ] Prevent injection with parameterized queries.
- [ ] Read a query plan and justify an index.
- [ ] Back up and restore PostgreSQL successfully.

## Architecture

- [ ] Separate business rules from transport and storage.
- [ ] Explain dependency injection in plain JavaScript.
- [ ] Define module boundaries and dependency direction.
- [ ] Explain when a modular monolith is enough.
- [ ] Identify where consistency, idempotency, caching, or queues matter.

## Testing and security

- [ ] Choose between unit, integration, contract, and end-to-end tests.
- [ ] Test failures and edge cases, not only successful paths.
- [ ] Validate untrusted input at boundaries.
- [ ] Enforce authentication and authorization separately.
- [ ] Keep secrets and sensitive values out of repositories and logs.

## DevOps

- [ ] Diagnose a process, port, DNS, TLS, permission, and disk problem.
- [ ] Build and inspect a container image.
- [ ] Configure a reverse proxy and health check.
- [ ] Read application and system logs.
- [ ] Deploy and roll back predictably.
- [ ] Verify monitoring plus backup restoration.
