# Learning Rules

## Allowed

- Official documentation
- Existing code written in this repository
- Small AI hints
- Code review after an attempt
- Debugging questions that explain an error
- Searching for API syntax

## Not allowed for the first attempt

- Asking AI to implement the whole exercise
- Copying a completed tutorial project
- Adding a framework to avoid the required low-level work
- Checking a mastery item without evidence

## Work cycle

1. Read the requirements.
2. Predict the behavior.
3. Write a failing test.
4. Implement the smallest working change.
5. Run the test.
6. Refactor names and structure.
7. Commit one coherent change.
8. Explain it verbally in two minutes.

## When blocked

Use this short format:

```text
Goal:
Observed:
Expected:
Tried:
Current hypothesis:
```

This is enough. Long paragraphs are not required.
