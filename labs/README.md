## Review gate

Before unlocking the next lab:

- [ ] Acceptance checks pass.
- [ ] Failure paths are tested.
- [ ] The implementation can be explained verbally.
- [ ] One bug can be diagnosed without generated code.
- [ ] Evidence is linked in [`../PROGRESS.md`](../PROGRESS.md).
